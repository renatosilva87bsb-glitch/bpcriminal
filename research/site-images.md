# Imagens institucionais usadas no site

As imagens foram selecionadas para aproximar visualmente o escritório do contexto institucional de Brasília, sem sugerir vínculo com os tribunais.

- **STF:** `assets/courts/stf-palacio.jpg`, Supremo Tribunal Federal, Brasília. Autor Rob Sinclair. Licença CC BY-SA 2.0. Fonte: https://commons.wikimedia.org/wiki/File:Supreme_Federal_Court_of_Brazil.jpg
- **TJDFT:** `assets/courts/tjdft-palacio.jpg`, Palácio da Justiça do TJDFT. Autor Borowskki. Declaração de domínio público na página do arquivo. Fonte: https://commons.wikimedia.org/wiki/File:TJDFT_2012.jpg

Os créditos também aparecem no rodapé do site. As imagens foram redimensionadas/comprimidas para uso web; essa alteração não muda a atribuição das obras.
